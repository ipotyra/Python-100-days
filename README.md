# 100 Days of Code — Python Bootcamp

This repository contains my exercises and projects from the **100 Days of Code: The Complete Python Pro Bootcamp** (Udemy).

## About

The course covers Python fundamentals through hands-on daily projects, progressing from beginner concepts to more advanced topics like web development, automation, data science, and APIs.

## Structure

Each folder corresponds to a day (or project) from the course:

```
├── day-01-working-with-variables/
├── day-02-data-types-and-strings/
├── day-03-control-flow-and-logical-operators/
├── day-04-randomisation-and-python-lists/
├── day-05-python-loops/
├── day-06-python-functions-and-karel/
├── day-07-hangman/
...
```

## Topics Covered

- Working with Variables in Python to Manage Data
- Understanding Data Types and How to Manipulate Strings
- Control Flow and Logical Operators
- Randomisation and Python Lists
- Python Loops
- Python Functions & Karel
- Hangman (project)
- ...more to come as the course progresses

## How to Run

Each day's folder contains its own `.py` file(s). To run an exercise:

```bash
cd day-XX-topic-name
python3 exercise.py
```

## Notes

This repo is for learning purposes — code quality and structure will improve as the course progresses.
